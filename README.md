# 👋 Meu Currículo Online

Site pessoal em formato de currículo, desenvolvido como projeto final de um curso de **HTML e CSS**. Reúne uma apresentação, informações sobre mim, meus projetos e formas de contato.

🔗 **Acesse o site:** https://pedrolucas-pf.github.io/

---

## 📄 Páginas

| Página | Descrição |
| --- | --- |
| **Home** | Apresentação e boas-vindas |
| **Sobre** | Foto e um pouco sobre minha formação e interesses |
| **Projetos** | Trabalhos da graduação, de extensão e projetos pessoais |
| **Contato** | Links para LinkedIn, Instagram e outros canais |

---

## 🛠️ Tecnologias e conceitos utilizados

- **HTML5** com tags semânticas (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS3** em um único arquivo compartilhado por todas as páginas
- **Flexbox** para menu, cartões de projetos e alinhamento dos contatos
- Modelo de caixa (`padding`, `border`, `margin`), `border-radius` e `box-shadow`
- Layout adaptável a telas menores com `flex-wrap`
- Planejamento prévio com **wireframes**
- Versionamento com **Git** e **GitHub**

## 🚀 Como rodar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd NOME-DO-REPOSITORIO
   ```

3. Abra o arquivo `index.html` no navegador. Se usar o VS Code, a extensão **Live Server** atualiza a página automaticamente a cada alteração.
